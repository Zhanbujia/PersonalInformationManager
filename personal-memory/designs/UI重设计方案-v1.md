# 拾穗 · UI 重设计方案 v1

> 配套高保真原型：`designs/ui-prototype-v1.html`（单文件，可直接双击打开；支持明暗主题、⌘K 命令面板、八个页面切换）
>
> 设计关键词：**纸感 · 安静 · 可信 · 顺手**。不是做一个更花哨的后台，而是做一个愿意每天打开的个人资料桌面。

---

## 1. 现状诊断

从现有页面与代码看，功能已经完整，但界面更像"开发者给自己搭的工具"，离"每天都想用"还有距离：

| 问题 | 具体表现 | 影响 |
|---|---|---|
| 导航平铺 | 记一笔 / 收件箱 / 问一句 / 待办 / 回顾 / 资料库 全部同级 | 新用户建立不了"收集 → 整理 → 使用"的心智 |
| 层级偏弱 | 标题、正文、辅助信息字号/颜色接近，白底细边框卡片大量重复 | 一屏找不到视觉重心，扫读成本高 |
| 状态不统一 | 加载、空状态、失败、禁用各写各的；问答曾直接显示异常类名 | 用户不知道"现在发生了什么、下一步做什么" |
| 入口分散 | 新建、上传、搜索散落各页，缺全局入口 | 高频动作路径长 |
| 缺少"今日" | 打开后落在"记一笔"，没有总览 | 不知道今天该推进什么 |
| 可访问性 | 焦点态、对比度、键盘操作不完整 | 键盘用户/低视力用户不友好 |
| 品牌感弱 | 绿色点缀 + 通用卡片，缺少独特气质 | 记不住、不像"我的"工具 |

---

## 2. 设计目标与原则

**目标**

1. 打开 3 秒内知道"现在能做什么"。
2. 收集零摩擦：一个快捷键、一个输入框、一次拖拽。
3. 知识可被发现：文件夹、搜索、引用、关联都可回溯。
4. 可信：每条结论有出处，每个状态有反馈。
5. 美观但克制：用留白、层次和材质，而不是堆装饰。

**五条原则**

- **安静优先**：界面退后，内容在前；一屏只保留一个主行动。
- **渐进披露**：列表只给判断所需信息，详情在抽屉/预览里展开。
- **可逆**：删除是软删除，移动/重命名即时可改，危险操作二次确认。
- **一致反馈**：加载有骨架、空有引导、错有原因、成有确认。
- **键盘友好**：⌘K 全局、Enter 发送、Esc 关闭、Tab 焦点可见。

---

## 3. 信息架构

把 7 个平级入口收成 **4 组**，降低选择成本：

```
今日                        ← 总览与快捷入口
收集
  ├─ 记一笔                 ← 纯输入
  └─ 收件箱                 ← 所有记录与分类
知识
  ├─ 资料库                 ← 文件与文件夹
  └─ 问一句                 ← 对话式检索
行动
  ├─ 待办
  └─ 回顾
设置 / 帮助（底部）
```

- **今日** 是新的默认落地页：快捷记录、今日待办、最近记录、本周回顾摘要。
- **记一笔** 只负责"收进来"，不再承担列表职责。
- **收件箱** 负责"回看与整理"，提供类型筛选、搜索、展开详情。
- **资料库** 与 **问一句** 放在"知识"组，明确它们是"用起来"的两种方式。
- **待办 / 回顾** 放在"行动"组，回答"接下来做什么"。

## 4. 设计语言

### 4.1 色彩

以"纸 + 墨 + 森林绿 + 一点金"为主。金色只用于引用、编号、重点，不滥用。

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `--bg` | `#F5F2EA` | `#0F1713` | 页面底色（暖纸） |
| `--surface` | `#FFFFFF` | `#17241D` | 卡片 |
| `--ink` | `#1E2A24` | `#ECE8DD` | 主文字 |
| `--muted` | `#7A847D` | `#8B968F` | 辅助文字 |
| `--line` | `#E4DED0` | `#283A30` | 分隔线/边框 |
| `--forest` | `#1D3A2C` | `#0B120E` | 侧边栏 |
| `--green` | `#2F6B4F` | `#6FB08C` | 主行动/选中 |
| `--green-soft` | `#E7F0EA` | `#1C3328` | 选中底/浅强调 |
| `--gold` | `#B08145` | `#D2A36A` | 引用角标/品牌点缀 |
| `--warn` | `#A9651F` | `#E0A96D` | 待处理/到期 |
| `--danger` | `#A33A3A` | `#E08A85` | 删除/失败 |

对比度：正文 ≥ 4.5:1；大字号/图标 ≥ 3:1。深色模式不反相，单独调色。

### 4.2 字体

- 正文/界面：`"PingFang SC", "Microsoft YaHei", "Segoe UI", system-ui, sans-serif`
- 数字：`font-variant-numeric: tabular-nums`（统计、token、时间对齐）
- 字号阶梯：`26 / 20 / 16 / 14 / 13 / 12 / 11`（px），行高 `1.6–1.8`
- 字重：标题 600，正文 400，强调 500；不靠加粗堆层级，靠字号与留白

### 4.3 间距 / 圆角 / 阴影

- 间距基数 **4px**，常用 `8 / 12 / 16 / 20 / 28`
- 圆角：小件 `10`，卡片 `14`，对话气泡/大容器 `20`
- 阴影：默认极轻（`0 1px 2px` + `0 8px 24px` 低透明），悬浮层用大阴影
- 边框优先于阴影：纸感界面里 1px 暖灰线比投影更干净

### 4.4 图标与动效

- 线性图标，1.6px 描边，18/20px，`currentColor`
- 动效：120ms（hover）/ 180ms（面板）/ ease-out；`prefers-reduced-motion` 下关闭
- 页面切换：淡入 + 4px 上移；不做夸张位移

## 5. 关键页面

### 5.1 今日（Dashboard）

- **顶部 Hero**：日期 + 问候 + 一句话说明 + 快捷输入框 + 「记一笔」
- **三张统计卡**：本周记录 / 资料库文件 / 未完成待办（带趋势或到期提醒）
- **两栏**：今天要做（可勾选）/ 最近记录（带类型图标与状态）
- **本周回顾摘要**：一段自动生成的文字 + 「查看完整回顾」
- 设计意图：给用户一个"每天打开的理由"，同时保留最高频的记录入口。

### 5.2 记一笔

- 单列大编辑器（不是小输入框），左侧类型 chips + 附件入口
- 底部一行：快捷键提示 + 主按钮
- 右侧：最近记录 / 小提示（桌面端充分利用横向空间）
- 支持拖拽文件，上传后显示解析状态 chip

### 5.3 收件箱

- 顶部：搜索 + 类型筛选 chips + 排序
- 列表行：类型图标、标题、摘要、标签、时间、分析状态
- 展开行：摘要、重点高亮（金色底）、关联记录、操作（重新分析/删除）
- 设计意图：从"翻列表"变成"快速定位 + 就地处理"。

### 5.4 资料库

- 三栏：文件夹 rail / 文件网格（可切列表）/ 右侧预览抽屉
- 文件夹显示文件数；悬停出现改名/删除
- 文件卡：类型色块 + 名称 + 大小/时间 + 解析状态
- 预览：元数据、下载/改名/移动/删除、抽取正文
- 设计意图：像 Finder/网盘一样符合直觉，同时保留"解析后可检索"的产品差异。

### 5.5 问一句

- 左：历史会话（新建/切换/改名/删除，显示条数与时间）
- 右：对话流 + 输入区（附件、图片预览、停止、复制）
- 回答：Markdown + 金色引用角标 `[1]`，底部列出来源
- 空状态：3 个示例问题 + 附件说明
- 设计意图：明确的"有记忆的对话"，而不是一次性搜索框。

### 5.6 待办

- 按"今天 / 本周 / 以后"分组，勾选即完成
- 优先级用小圆点（不抢主信息），来源记录可回溯
- 已完成折叠，避免干扰

### 5.7 回顾

- 周期切换（本周/本月）+ 「生成回顾」
- 统计卡：记录数 / 新增标签 / 完成任务
- 正文三段：记了什么 / 几条线索 / 建议接下来做什么；建议挂证据链接
- 设计意图：把"总结"变成可核对、可行动的页面，而不是一段漂亮文字。

### 5.8 设计系统（原型内）

集中展示颜色、字体、按钮、输入、标签、卡片、空状态，方便评审与前端对齐。

## 6. 组件与状态

| 组件 | 状态 |
|---|---|
| Button | primary / secondary / ghost / danger / disabled / loading |
| Input / Textarea | default / focus / error / disabled |
| Chip / Tag | default / active / removable |
| Card | default / interactive（hover 抬升） |
| List Row | default / hover / selected / expanded |
| Badge | 类型（PDF/DOC/XLS/PPT）、状态（排队/解析/失败） |
| Avatar | 用户 / 品牌 |
| Toast | success / info / error（2s 自动消失） |
| Dialog | 确认 / 表单 / 预览 |
| Empty | 插画位（用图标 + 文案，不堆图） |
| Skeleton | 列表/卡片加载 |

统一规则：所有可点击元素 hover 有反馈、focus-visible 有 2px 绿色描边、disabled 透明度 45%。

---

## 7. 交互与快捷键

- `⌘/Ctrl + K`：命令面板（跳转页面、新建、搜索）
- `Enter` 发送 / `Shift + Enter` 换行（问答、记一笔）
- `Esc` 关闭弹层/命令面板
- `⌘/Ctrl + Enter` 提交记录
- 拖拽文件到页面任意位置：上传（资料库/问答）
- 删除：二次确认；删除后 Toast 提示并可撤销（后续版本）

---

## 8. 无障碍与响应式

- 所有图标按钮带 `aria-label`；导航用 `<nav>`；当前页 `aria-current="page"`
- 焦点顺序与视觉顺序一致；不隐藏焦点
- 触摸目标 ≥ 40×40px
- 断点：`≥1100` 三栏；`900–1100` 两栏；`<900` 单栏（侧边栏横向滚动）
- 尊重 `prefers-reduced-motion`；支持 `prefers-color-scheme`（默认跟随，可手动切换）

## 9. 落地映射（现有 Vue 代码）

1. **设计令牌**：把 `frontend/src/styles.css` 的 `:root` 替换为本方案变量，新增 `[data-theme="dark"]`。
2. **布局**：`App.vue` 改为分组侧边栏 + 顶栏（标题/搜索/主题/头像）；新增 `/today` 路由作为默认首页。
3. **页面**：`Capture.vue / Inbox.vue / Library.vue / Ask.vue / Todos.vue / Digest.vue` 按第 5 节调整结构；新增 `Today.vue`。
4. **组件**：抽出 `Button`、`Chip`、`Card`、`ListRow`、`EmptyState`、`Toast`、`CommandPalette` 到 `components/ui/`。
5. **图标**：用内联 SVG sprite（原型已给），不引第三方图标字体。
6. **迁移顺序**：令牌 → 布局/导航 → 今日 → 记一笔/收件箱 → 资料库/问答 → 回顾/待办 → 暗色与无障碍。

## 10. 验收清单

- [ ] 明暗两套主题下正文对比度 ≥ 4.5:1
- [ ] 1440 / 1280 / 1024 / 768 / 390 五个宽度不溢出、不挤压
- [ ] 每个页面有加载、空、错误三种状态
- [ ] ⌘K 可打开/关闭，方向键可选择，Esc 关闭
- [ ] 所有交互元素有 hover / focus-visible / disabled
- [ ] 键盘可完成"记录 → 查看 → 提问"主路径
- [ ] 删除、移动、重命名有明确反馈
- [ ] 无控制台报错；首屏无布局跳动

## 附：原型使用

打开 `designs/ui-prototype-v1.html`：
- 左侧导航切换 8 个页面；`⌘/Ctrl + K` 打开命令面板；右上角切换明暗主题。
- 页面内按钮大多会弹 Toast（标注"原型演示"），用于展示反馈节奏。
- 原型是**设计验证件**，不是生产代码；确认方向后再按第 9 节落到 Vue。
